# EA-PDF Desktop Viewer

Read EA-PDF archives and PDF Portfolios in a desktop window. Browse messages and folders, open or save attachments, search document text, and export metadata.

[Download Desktop Viewer 0.8.0](https://github.com/thinkbox-digital/eapdf-secure/releases/download/v2.3.2/eapdf-desktop-viewer-secure-0.8.0.jar). Install a desktop version of Java 21 or later and double-click the JAR. In the viewer, choose **Open PDF…** or drag a PDF into the window. If an archive app opens when you double-click the JAR, use **Open with** and select Java.
