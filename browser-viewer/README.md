# EA-PDF Viewer Experimental

Read EA-PDF archives in Chromium or Firefox. Open a PDF, browse its messages and folders, and view or save attachments.

Download the [Chromium or Firefox package](https://github.com/thinkbox-digital/eapdf-secure/releases/tag/v2.4.0-beta.2) and follow the [browser installation guide](../docs/manual/user-manual.html#viewer). To open PDFs in a separate app, use [Desktop Viewer](https://github.com/thinkbox-digital/eapdf-secure/releases/download/v2.4.0-beta.2/eapdf-desktop-viewer-secure-0.9.0.jar).

Secure has a separate Firefox add-on ID so it can coexist with Main.
If Firefox lists an older EA-PDF Viewer Experimental, remove that entry
before loading the new Secure manifest.
