# Full browser reader

Read EA-PDF archives in Chromium or Firefox. Open a PDF, browse its messages and folders, and view or save attachments.

Download the [Chromium or Firefox package](https://github.com/thinkbox-digital/eapdf-secure/releases/tag/v2.3.2) and follow the [browser installation guide](../docs/manual/user-manual.html#viewer). To open PDFs in a separate app, use [Desktop Viewer](https://github.com/thinkbox-digital/eapdf-secure/releases/download/v2.3.2/eapdf-desktop-viewer-secure-0.8.0.jar).
