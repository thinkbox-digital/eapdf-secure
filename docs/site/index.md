# EA-PDF Secure

Convert email into preservation PDFs and check digital signatures, timestamps and provenance.

[Download the apps](downloads.md) · [Get the tools ready](manual/installation.md) · [Read a PDF](manual/viewer.md)

Double-click the Desktop Viewer JAR, then choose **Open PDF…** or drop a PDF into the window. Use Validator to check the file separately. Keep your original email files when you convert them.
