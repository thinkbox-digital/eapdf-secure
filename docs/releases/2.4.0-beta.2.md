# EA-PDF Secure 2.4.0-beta.2

This prerelease includes creator and validators 2.4.0-beta.2, the Full browser
viewer 1.35.0 for Chromium and Firefox, and the desktop viewer 0.9.0.

- Multi-file publication provides a generation manifest for reading a complete
  batch. Individual PDF paths remain available for direct access.
- Input processing, validation workers, and publication recovery enforce
  resource limits and preserve existing files on failed jobs.
- Gmail authorization stays in memory by default. Supply
  `EAPDF_GMAIL_TOKEN_PASSWORD` to use encrypted local token persistence.

Use Java 21 and the [Secure setup guide](../DIGITAL_SIGNATURES.md) for signed
exports. Release downloads include `SHA256SUMS`.
