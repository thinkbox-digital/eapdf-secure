EA-PDF Secure 2.3.2 includes Full browser reader 1.33.0 and Desktop Viewer 0.8.0.

- The desktop viewer opens local EA-PDF archives and PDF Portfolios, with message navigation, search, attachment export and CSV/XMP export.
- The Full browser reader updates its signature verification dependencies.

Use Java 21 or later. The creator includes a Linux x86-64 rendering runtime. Extract the configuration ZIP beside the creator. Open a document with `java -jar eapdf-desktop-viewer-secure-0.8.0.jar /path/to/archive.pdf`.
