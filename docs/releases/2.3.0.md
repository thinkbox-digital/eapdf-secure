# EA-PDF Secure 2.3.0

First release of the separate Secure edition. The creator and both Java
validators are 2.3.0; the Full browser reader is 1.31.0.

- The creator supports optional C2PA provenance and PAdES B-LTA signing.
- The standalone Security Validator checks C2PA and PAdES independently of
  EA-PDF and PDF/A conformance. The browser reader also reports export-security
  evidence.
- Gmail exports use bounded parallel conversion, with completed and total
  message counts visible throughout the run.

Install Java 21 or later for the creator and validators. Chromium and Firefox
packages are unsigned. See the [user manual](../EA-PDF_User_Manual.pdf) and
[signing setup](../DIGITAL_SIGNATURES.md) for certificate, timestamp and trust
configuration.
