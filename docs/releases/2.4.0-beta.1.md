EA-PDF Secure 2.4.0-beta.1 is a prerelease. It includes the browser reader 1.34.0 and Desktop Viewer 0.9.0.

- The creator protects selected sources and keeps concurrent output jobs separate.
- Validation reports protect input files and identify incomplete invocations.
- Desktop reader cancellation limits concurrent parsing. Release checks exercise the published JARs.

Use Java 21 or later. The creator bundles a Linux x86-64 rendering runtime. C2PA, PAdES signing and verification are experimental. Test trust material was synthetic. Production timestamp services and independent C2PA interoperability remain unverified.
